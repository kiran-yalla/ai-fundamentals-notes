# ai-fundamentals-notes

Personal learning notes and exercises covering AI & Machine Learning fundamentals: core concepts, generative AI, LLMs, prompt engineering, and responsible AI basics.

## What this demonstrates

- 📚 **Structured self-learning** — an organized set of notes documenting the AI/ML learning journey from first principles
- 🧠 **AI/ML fundamentals** — supervised/unsupervised learning, neural networks, and key terminology
- 🤖 **Generative AI & LLMs** — how large language models work and common ways to use them
- 💬 **Prompt engineering** — zero-shot, few-shot, chain-of-thought, and role prompting basics
- ⚖️ **Responsible AI** — fairness, transparency, privacy, and accountability basics

## Structure

```
ai-fundamentals-notes/
├── 01-ai-ml-basics.md              # Core AI/ML concepts and terminology
├── 02-generative-ai-and-llms.md    # Generative AI and LLM fundamentals
├── 03-prompt-engineering-basics.md # Prompt engineering techniques and best practices
└── 04-responsible-ai-and-ethics.md # Responsible AI principles and practical takeaways
```

## Usage

These are Markdown notes meant to be read directly on GitHub — start with `01-ai-ml-basics.md` and work through in order.

> 📘 This is a personal learning journal, not a formal course or authoritative reference. Related hands-on examples live in the `genai-prompt-engineering-basics` and `llm-chatbot-starter` repos.
